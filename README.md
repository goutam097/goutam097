# 💫 About Me:
Goutam Singh is a Frontend Developer with 3 years of experience building high-performance web applications using technologies like React.js, Next.js, JavaScript, and TypeScript. He has strong expertise in developing scalable UI architectures, optimizing performance, and implementing real-time features such as messaging and video streaming systems. Currently working as a Senior Developer at Shanviatech Solution Pvt. Ltd., he has led frontend development for large-scale platforms serving thousands of users while improving performance and code efficiency. He also has experience working with Node.js, MongoDB, Redux, and REST APIs, and has successfully delivered projects including social media platforms, insurance portals, and e-learning systems.
